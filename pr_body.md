## Resumo
Implementa uma tela de login simples em React com validacao de credenciais conforme enunciado.

## O que foi feito
- Titulo "Login"
- Input de e-mail
- Input de senha
- Botao "Acessar"
- Label de retorno abaixo do botao
- Regra de validacao:
  - Sucesso quando e-mail = `eduardo.lino@pucpr.br` e senha = `123456`
  - Erro para qualquer outro valor

## Mensagens esperadas
- Sucesso: "Acessado com sucesso!"
- Erro: "Usuario ou senha incorretos!"

## Como testar
1. Executar `npm install`
2. Executar `npm run dev`
3. Abrir a URL local exibida pelo Vite
4. Testar com credenciais validas e invalidas
